# Zoom Recorder

Windows 11에서 회의 소리와 마이크를 녹음하고, 끝난 회의를 글로 바꾸는 데스크톱 앱입니다.
**GitHub Releases의 ZIP을 내려받으면 Python, Git, 터미널, CLI AI 에이전트 없이 사용할 수 있습니다.**

## 처음 사용하는 분

1. 이 저장소의 **Releases**에서 `ZoomRecorder-Local-windows-x64.zip`을 받습니다.
2. ZIP을 우클릭해 **모두 압축 풀기**를 선택합니다. 압축 파일 안에서 바로 실행하지 마세요.
3. 풀린 폴더의 **ZoomRecorder-Local.exe**를 더블클릭합니다. `_internal` 폴더도 함께 보관합니다.
4. **녹음 시작 → 참석자 동의 확인 → 동의하고 녹음 시작**을 누릅니다.
5. 회의가 끝나면 **녹음 중지**를 누르고 저장 폴더명을 확인합니다.

처음 실행하면 **녹음만** 합니다. 계정이나 API 키 없이 MP3를 저장할 수 있습니다.
상세한 사용법은 ZIP 안의 **START_HERE.html**을 더블클릭해 읽으세요. 인터넷 없이도 열립니다.

| 다운로드 | 사용할 때 |
|---|---|
| **Local ZIP** | 이 PC에서 녹음과 전사까지 처리하려는 경우. 기본 선택으로 권장합니다. |
| Lite ZIP | 녹음만 하거나, 별도 API 키·전송 동의로 OpenAI 전사를 사용하는 경우. |
| Source code / source ZIP | 직접 코드를 수정하는 개발자용입니다. 일반 사용자는 위 EXE ZIP을 받으세요. |

## 녹음을 글로 바꾸기

Local 앱의 **환경설정 → 일반**에서 `녹음 + 전사`를 선택합니다.
**전사** 탭에서 `이 PC에서 처리 · 로컬`, `CPU`, `small`을 선택한 뒤 **선택 모델 다운로드**를 누릅니다.
다운로드가 끝나면 **설정 저장**을 누릅니다. 모델을 처음 받을 때 인터넷이 필요하며 이후 로컬 전사는 오프라인으로 사용할 수 있습니다.
모델만 내려받고 녹음은 전송하지 않습니다. API 키는 필요 없습니다.

GPU는 호환되는 NVIDIA CUDA/cuDNN 환경이 있는 경우 선택합니다. 처음에는 CPU로 확인하세요.
GPU 실행 라이브러리와 전사 모델은 ZIP에 포함되어 있지 않습니다. 큰 모델은 메모리와 처리 시간이 더 필요합니다.

## 하루 동안 사용하는 흐름

- 이전 회의 전사 중에도 **다음 녹음**을 시작할 수 있습니다. 새 회의마다 동의를 다시 확인합니다.
- 전사는 한 건씩 순서대로 처리하며 최근 회의에서 상태를 확인합니다.
- **전사문 열기**, **내용 복사**, **전사 / 재시도**, **폴더 열기**를 제공합니다.
- 기본 **2분 동안 발화가 감지되지 않으면** 소리 없는 알림창을 보여줍니다. 자동으로 녹음을 끊지 않습니다.
- 알림에서 **녹음 중지**, **5분 뒤 알림**, **이번 녹음 알림 끄기**를 고릅니다.
- 환경설정에서 무발화 알림 시간, 창 앞으로 표시, 장시간 녹음 알림을 변경할 수 있습니다.
- 창의 **X**는 트레이로 숨깁니다. 완전히 종료하려면 트레이 메뉴의 **종료**를 사용합니다.
- 녹음·저장·전사 대기 작업이 남아 있으면 앱 종료를 막습니다. 비정상 종료 후에는 복구와 재시도를 직접 선택합니다.

## 저장 위치와 업데이트

0.4.1의 **환경설정 → 일반 → 음성 보관**에서 두 옵션을 독립적으로 선택합니다.
기본값은 **MP3 변환 ON / 전사 후 음성 삭제 OFF**입니다. 설정은 새 녹음 시작 때 고정하며 기존 녹음에는 소급 적용하지 않습니다.

| MP3 변환 | 전사 후 음성 삭제 | 동작 |
|---|---|---|
| OFF | OFF | 분리된 분할 WAV를 보관합니다. |
| ON | OFF | 개별/선택적 합본 MP3를 보관하고 검증 후 임시 WAV를 정리합니다. |
| OFF | ON | WAV로 전사한 뒤 음성을 삭제하고 전사문을 남깁니다. |
| ON | ON | 자동 전사라면 MP3 생성을 생략하고 전사 후 음성을 삭제합니다. 녹음만 모드에서는 MP3로 보관하다가 나중 전사 성공 후 삭제합니다. |

전사 후 삭제는 해당 세션이 생성한 WAV·MP3·합본을 모두 대상으로 합니다. 성공한 전사문과 해시,
비어 있지 않은 발화 결과, 녹음 누락 여부를 확인합니다. 실패·빈 결과·누락·파일 변경은 음성을 보존합니다.
삭제 후에는 전사문을 열고 복사할 수 있지만 음성 재생/재전사는 불가능합니다. 삭제된 음성 링크는 전사문에 넣지 않습니다.
중간 종료 후에는 **저장·삭제 재시도**로 이미 확인한 파일만 이어서 정리하며 자동 재전송하지 않습니다.
합본 MP3는 MP3 보관이 필요한 경우에만 생성합니다. 변환 OFF는 개별 분할 WAV 보관입니다.

아래 MP3 저장 설명은 MP3 변환 ON / 전사 후 삭제 OFF일 때의 동작입니다.

0.4.0에서는 **환경설정 → 일반 → 음성·전사 저장 위치 → 폴더 선택**으로 저장 위치를 지정합니다.
위치 변경은 모든 처리를 마치고 트레이에서 앱을 종료한 뒤 다시 실행하면 적용됩니다.
이전 위치의 녹음도 최근 회의/복구에서 접근할 수 있으며 기존 파일을 자동 이동하지 않습니다.

녹음 시작 화면에서 **PC 소리 / 마이크**를 선택합니다. 기본은 둘 다이며 최소 하나가 필요합니다.
환경설정에서 기본 대상과 합본 생성을 변경합니다. 녹음 도중에는 대상이 바뀌지 않습니다.

새 녹음은 회의 폴더 안에 `PC음성.mp3`, `마이크음성.mp3`, 두 음성을 선택한 경우 `합본.mp3`를
128kbps로 저장합니다. 한 음성만 선택하면 해당 파일만 생성합니다. 합본은 두 음성을 같은 비율로
혼합하며 개별 파일보다 작게 들릴 수 있습니다. 시작 시각 차이/누락 구간은 무음으로 채웁니다.
장시간 장치 클록 드리프트와 스피커 에코를 자동 제거하는 기능은 아닙니다.

녹음 중에는 `audio/`에 임시 WAV가 쌓이므로 충분한 여유 공간이 필요합니다.
MP3의 전체 디코딩·길이·해시 검증과 요청한 전사가 모두 끝나면 **이번 회의의 임시 WAV만 자동 삭제**합니다.
오류·누락·미완료 전사·복구 자료가 있으면 WAV를 보존하고 이유를 표시합니다.
최근 회의의 **저장·삭제 재시도**는 외부 전송 없이 변환/정리를 재시도합니다.
미완료 전사가 있으면 **전사 / 재시도**를 먼저 완료해야 WAV가 삭제됩니다.
기존 버전에서 녹음한 파일은 자동 변환·삭제하지 않습니다.

나중 전사는 개별 MP3를 사용합니다. 전사문은 **PC 음성 · 시스템 출력 / 마이크**로 구분하고
합본을 중복 전사하지 않습니다. 입력 출처 구분이며 PC에서 말하는 여러 사람의 신원을 판별하지 않습니다.

EXE 앱의 녹음·전사문은 `%LOCALAPPDATA%\ZoomRecorder\recordings`에 저장됩니다.
앱의 **녹음 폴더 보기**를 누르면 실제 폴더를 엽니다. 설정과 모델도 `%LOCALAPPDATA%\ZoomRecorder` 아래에 있습니다.

업데이트할 때는 모든 작업을 마치고 앱을 종료한 뒤 새 ZIP을 **새 폴더에 전부** 풉니다.
EXE만 바꾸거나 `_internal`을 일부 섞지 마세요. 기존 개인 데이터와 설정은 유지됩니다.
제거하려면 앱에서 로그인 자동 실행을 끄고 종료한 뒤 압축을 푼 앱 폴더를 삭제합니다.
녹음과 모델은 별도 데이터 폴더에 남으므로 보관 여부를 직접 결정할 수 있습니다.

## 확인할 점

- 녹음은 기본 OFF이며 동의 확인과 시작 클릭이 있어야 시작합니다.
- **PC 전체 출력과 마이크**를 저장하므로 Zoom 외 다른 앱 소리도 포함됩니다. Zoom 공식 녹음 기능과 별개입니다.
- Zoom 앱·탭 감지는 후보 안내이며 회의 확정이 아닙니다. 브라우저 확장 없이도 수동 녹음을 사용할 수 있습니다.
- 발화 감지는 로컬 [WebRTC VAD](https://github.com/daanzu/py-webrtcvad-wheels)를 사용합니다. 다른 앱의 음성도 감지할 수 있습니다.
- API 방식은 별도 키와 세션별 전송 동의가 필요하며 요금이 발생합니다. 새 설치에서 오디오를 자동 업로드하지 않습니다.
- ZIP은 코드 서명되지 않은 Windows x64 배포본입니다. 보안 도구가 차단하면 조직 담당자에게 확인하고 보안 기능을 해제하지 마세요.
- 테스트는 합성 음성과 가짜 캡처를 포함합니다. 실제 장치의 품질·무발화 감지 정확도는 짧은 테스트 녹음을 직접 청취해 확인하세요.
- 포함된 라이브러리의 라이선스는 ZIP의 `THIRD_PARTY_LICENSES`에 있습니다. 이 앱은 Zoom과 제휴한 제품이 아닙니다.

## 개발자용

앱 실행에는 AI 에이전트가 필요 없습니다. 소스를 수정할 때만 Windows x64와 Python 3.11 이상을 준비합니다.

```powershell
# 저장소 루트에서 실행
.\scripts\install.ps1 -Dev
.\.venv\Scripts\python.exe -m app.main
.\.venv\Scripts\python.exe -m pytest -q
.\scripts\build.ps1 -Flavor lite
.\scripts\build.ps1 -Flavor local
```

독립 복제에서는 `data/`에 개인 설정·녹음·모델, `logs/`에 로그, `dist/`에 배포본을 저장합니다.
상위 폴더에 `.zoom-workspace`가 있으면 상위의 `data/`, `logs/`, `releases/`를 사용합니다.
환경설정의 개인 파일은 `data/config/settings.yaml`이며, `config/settings.example.yaml`은 공유용 예시입니다.
모든 상대 녹음·모델 경로는 현재 작업 디렉터리가 아니라 개인 데이터 폴더 기준입니다.

이 폴더만 Git 저장소로 사용합니다. `.venv/`, 개인 데이터, 로그, 배포본은 제외합니다.
Git과 소스 ZIP에는 앱 코드·테스트·빌드 도구·사용자용 안내만 포함합니다.
개인 데이터·모델·키·개발 작업 로그는 포함하지 않습니다. 독립 복제는 상위 문서 없이 빌드할 수 있습니다.
